# 概要

## 全体

新たな支払い手段としてステーブルコイン払いが行われた場合の効果を検証する。

地域でJPYCを配り、店頭で使い、円に戻すまでの一連を実際に動かし、同じ運用を税・公共料金の払込票へ広げられるかを実証実験する。

### 第一段階

**案3　地域消費支援のJPYC配布**

加賀市様の地域消費支援として、JPYC配布から店頭QR支払い、事業者の円転までを一巡させ、事業者が経路1〜3のどれを選ぶか、用途制限どおりに支払先が限定されるかを確かめる。

e-加賀市民の方がステーブルコインで実際に支払いを滞りなく行えるのかや、地域消費支援の手段としてステーブルコインを活用することでコスト削減に繋がる等のメリットの明確化。

### 第二段階

**案1　払込票のステーブルコイン払い**

第1段階で確かめた運用手順と精算実務を、加賀市様の払込票の収納（受付→照合→収納機関への日本円振込）に適用できるかを確かめる。

ステーブルコインによる支払いのPros, Consを明らかにし、今後も有用な支払い手段として活用が可能かを確認する。
