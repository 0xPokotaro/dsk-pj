## 第一弾：地域消費支援のJPYC配布

### 用語の定義

ユーザーが e-加賀市民でウォレットを連携する。そのウォレットで e-加賀市民証を保有し、かつマイナンバーカードによる JPKI 確認をしたユーザーが「JPYC配布対象者」になる。市民証の保有と JPKI 確認は、このユーザーについての二つの条件である。

| 段階 | 内容 |
| --- | --- |
| ユーザー | 起点となる人 |
| ウォレット連携 | e-加賀市民の機能として行う |
| e-加賀市民証を保有 | 連携したウォレットが e-加賀市民証NFTを持っている |
| JPKI確認 | マイナンバーカードによる公的個人認証を済ませている |
| JPYC配布対象者 | 市民証の保有と JPKI 確認の両方を満たすユーザー |

e-加賀市民証の内容は[e-加賀市民](../project/e-kaga-citizen)を参照。本ページで配布先を「e-加賀市民」と書くときは、この JPYC配布対象者を指す。

### 業務フロー

<KagaFlowDiagram />

1. **円 → JPYC**：加賀国家戦略特区推進機構が、法人ウォレットで円をJPYCにExchangeする
2. **配布**：加賀国家戦略特区推進機構が、e-加賀市民へJPYCを配布する
3. **支払い**：e-加賀市民が、市民アプリで地域事業者へJPYCを支払う
4. **受取後**：地域事業者が、法人ウォレットでJPYCを受け取る。その後の対応は[論点](#issue-after-receipt)を参照

### 論点：地域事業者がJPYCを受け取った後の対応 \{#issue-after-receipt\}

:::info[ステータス]

検討中（TBD）

:::

| 案 | 対応 |
| --- | --- |
| 1 | 地域事業者が自らJPYC EXで償還し、円を受け取る |
| 2 | CORGEARが受領・償還し、地域事業者へ円を振り込む |
| 3 | JPYCをそのまま保有する |

案2はCORGEARのウォレットが未定のまま受領を前提としており、関係者テーブルのウォレット欄は現状「―」である。この前提が成り立つなら、e-加賀市民の支払い先は常に地域事業者だけでなく、案2を選ぶ地域事業者についてはCORGEARが直接の支払い先になる可能性も残る。

## 第二弾：払込票のステーブルコイン払い

関係者・業務フロー・論点の詳細は[案1：払込票・eL-QRのステーブルコイン払い](./payment-slip)を参照。
第一弾（配布したJPYCの地域消費）とは異なり、第二弾は **e-加賀市民が保有するJPYCで加賀市への払込票を支払い、DSKが収納代行として円と収納データを加賀市へ届ける** 流れを検証する。

### 検証・実証項目（第二弾） \{#verification-phase2\}

| 区分 | 項目 | 内容 |
| --- | --- | --- |
| 市民アプリ | 払込票の読み取り | 市民アプリで払込票のバーコードを正しく読み取り、払込先・金額が正しく表示されるか（読み取り失敗率） |
| 市民アプリ | 支払いのUI/UX | 払込票のJPYC支払いを、利用者が迷わずスムーズに完了できるか |
| 市民アプリ | JPYCの償還 | e-加賀市民が市民アプリからJPYCを円に償還できるか。所要日数と上限・下限の制約 |
| 収納処理 | 支払いの確定 | JPYC支払いの着金確認から収納確定までの判定基準と所要時間 |
| 収納処理 | 収納データの連携 | DSKから加賀市への収納データが、既存の収納代行と同じ形式・タイミングで送信され、消込が行えるか |
| 収納処理 | 円の送金 | DSKが受け取ったJPYCを円に換え、加賀市へ送金するサイクルと着金日数 |
| 運用 | 例外事象の洗い出し | 支払期限切れ・二重払い・金額相違・取消・返金・決済失敗など、払込票の支払いで発生する例外とその頻度 |
| 運用 | 例外時の手順 | 上記の例外に対する加賀市・DSK・市民それぞれの対応手順が運用で回るか |
| 運用 | ログ取得 | 収納の証跡（誰が・いつ・どの払込票を・いくら）が取得でき、加賀市の照会に答えられるか |
| コスト・効果 | 手数料・ガス代の実額 | 支払い・償還・円転の各場面で発生する手数料・ガス代の実額と負担者 |
| コスト・効果 | 従来チャネルとの比較 | コンビニ収納・口座振替・窓口など既存の収納チャネルと比べた、加賀市・DSK双方のコストと事務工数 |
| コスト・効果 | 利用率 | 払込票全体のうちJPYCで支払われた件数・金額の割合と、第一弾で配布したJPYCがどの程度充当されたか |
