# e-加賀市民

## 概要

**e-加賀市民**は、住民票がなくてもインターネット上で石川県加賀市の市民になれる、日本初の「電子市民制度（加賀版e-Residency）」です。

## 主な特徴

- **関係人口の創出**：観光、ワーケーション、多拠点生活などで加賀市とつながる人を増やし、将来的な移住や定住につなげます。
- **デジタル市民証NFT**：マイナンバーカードを用いた公的個人認証と連携した「e-加賀市民証NFT」を発行しています。
- **特典や行政サービス**：NFTを持つことで、市内の協力店舗での割引や、移動・滞在に関するサポート、専用コミュニティへの参加などのサービスを受けられます。
- **ビジネス支援**：メタバース上のバーチャル窓口（加賀市ウェブ3課）などを活用したリモートでの開業相談や、スタートアップ支援も行っています。

## ウォレット

[NFT販売サイト](https://nft.kaga-e-residency.jp/)では、Torus Wallet と MetaMask の2種類のウォレットを使える。

<EKagaWalletDiagram />

:::caution

Torus Wallet（Web3Auth）は NFT販売サイト専用のウォレット。同じ Google アカウント・メールアドレスでも、他のサービスではアドレスが変わる（[Web3Auth調査](../web3auth.mdx)）。

秘密鍵はログイン中のブラウザ上で組み立てられる。エクスポートできるかはサイトの設定によるが、NFT販売サイトの設定は未確認。

:::
