# ステークホルダー

## 会社ごとの役割

| 会社 | プロジェクトにおける役割 |
| --- | --- |
| STARTALE GROUP PTE. LTD. | JPYSC（円建てステーブルコイン）とミニアプリ・ウォレットの提供元。技術プラットフォーム提供者であり、SBI VCトレード・新生信託銀行への橋渡し役も担う |
| 株式会社Unyte | 本POC全体を企画・推進するプロジェクトオーナー。大阪府との調整、金融庁への事前相談の段取り、関係各社間の合意形成を取りまとめる。2025年11月18日付で株式会社電算システムホールディングスの子会社となった |
| 大阪府 徴税対策課 | POCの対象となる自治体側カウンターパート。自動車税の収納へのJPYSC活用を検討する発注主体で、プロジェクト進行には合意取得が必須 |
| SBI VCトレード株式会社 | JPYSCを日本円に換金する交換業者。受け取ったステーブルコインを弊社経由で換金し、自治体へ振り込む資金フローの要 |
| 新生信託銀行株式会社 | JPYSCの信託事業者。金融庁（財務局経由）への事前相談はこの信託銀行を通じて行う想定で、規制対応上のキープレイヤー |
| 株式会社SBIホールディングス | 新生信託銀行・SBI VCトレードとの関係構築を仲介した紹介元（ブロックチェーン推進室経由） |
| 株式会社電算システム | Unyteの親会社（株式会社電算システムホールディングス傘下）。収納代行サービス・企業のIT基盤支援を行う。DAOの社会実装に向けてUnyteと業務提携済み |
