# 金融庁への説明

## 概要

大阪府徴税対策課（自動車税）を対象に、JPYSC（JPY建てステーブルコイン）を活用した納税POCについて、関係者全社の合意が取れた後に金融庁へ事前相談を行う。

## 進め方

1. **関係者全社合意**：大阪府（府県戦略調整局・徴税対策課・システムグループ）、Startale、SBI VCトレード、新生信託銀行の合意を得る
2. **スキームの整備**：内容を整備してから確認を取るフローとし、事前確認後に案件が頓挫した場合のコミュニケーションリスクを回避する
3. **新生信託銀行経由で財務局へ連絡**：信託事業者である新生信託銀行を通じてコンタクトする
4. **金融庁への事前相談**：DSK（Unyte）も同席見込み。ケースによりStartaleも同席
