# 概要

大阪府徴税対策課を対象に、自動車税の収納へJPYSC（円建てステーブルコイン）を活用するPoCを検討している。

プロジェクトは検証フェーズと実証フェーズに分け、検証フェーズで仕組みが動くことを確かめたうえで、実証フェーズへ進むかを判断いただく。

- 検証フェーズ：本部コード追加なしで、支払い・検知・収納データ生成までの一連の仕組みを確認する
- 実証フェーズ：本部コードの追加対応を行い、本番環境でJPYSC決済から日本円入金までを実施しKPIを測定する

## プロジェクトの工程

| フェーズ | 工程 | 内容 |
| --- | --- | --- |
| 検証フェーズ | 着手前 | 関係者合意・金融庁への事前相談 |
| 検証フェーズ | 要件定義 | 支払いから収納データ連携までの要件定義 |
| 検証フェーズ | 設計 | 基本設計・詳細設計 |
| 検証フェーズ | 開発 | SC収納システム・収納代行連携・ミニアプリの開発 |
| 検証フェーズ | 検証 | テスト用の払込票・トークンで確認 |
| 検証フェーズ | 実証実施の判断 | 検証結果をもとに実証へ進むかを判断 |
| 実証フェーズ | 本部コード追加 | 本部コードの追加対応と従来業務の確認 |
| 実証フェーズ | 実証 | 本番環境でJPYSC決済から入金までを実施しKPIを測定 |
| 実証フェーズ | 評価 | 評価報告書作成、Step2検討 |
