# 全体像

## システム全体像

料金通知から大阪府徴税対策課様への入金までの流れ。

### 現行の流れ（コンビニ収納）

大阪府徴税対策課様が払込票を郵送し、納税者がコンビニ店頭で支払う。DSKが収納・消込データを連携し、日本円で大阪府徴税対策課様へ払い込む。
